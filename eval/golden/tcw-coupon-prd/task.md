## 输入材料

### 材料 1：PRD《优惠券创建功能》v1.2

**功能目标**：运营在管理后台创建优惠券模板，供 C 端用户领取使用。

**角色**：运营（可创建/编辑/发布优惠券）；管理员（额外可手动提前结束进行中的活动）。

**创建表单字段与规则**：

1. **券名称**：必填，不超过 20 个字符，同商户下名称唯一（重复时提示"名称已存在"）
2. **面额**：必填，1–1000 元整数（单位：元）
3. **使用门槛**：必填，0 表示无门槛；非 0 时必须 ≥ 面额
4. **有效期类型**：二选一
   - 固定时间段：开始时间、结束时间（开始必须早于结束，跨度不超过 90 天）
   - 领取后 N 天有效：N 取值 1–30
5. **发放总量**：必填，1–100000 张
6. **每人限领**：必填，1–10 张

**状态流转**：待发布 → 已发布 → 已结束。到达结束时间后自动变为已结束（系统定时任务，1 小时内生效）；管理员可对已发布的券手动提前结束。

**编辑规则**：待发布状态可编辑全部字段；已发布状态仅可编辑发放总量（只能调大）；已结束不可编辑。

**FAQ**：
- Q：无门槛券和有门槛券可以同时持有吗？A：可以叠加持有，但同一订单结算时只能使用其中一张。
- Q：券名称可以与其他商户重复吗？A：可以，唯一性仅在同商户内校验。

**非目标**：本期不支持跨商户使用；不支持券的转赠。

**异常场景**：表单任一必填项缺失时，提交按钮置灰；格式错误在对应字段下方红字提示，提交不中断其他字段的填写状态。
