# 积分商城兑换 测试用例

## 测试环境与前置条件

- 环境：测试环境（后台与测试账号向测试组长索取）
- 数据准备：
  - 账号 A：积分余额 ≥ 商品 X 积分价（建议 ≥ 1000），当日兑换次数 = 0
  - 账号 B：积分余额 < 商品 X 积分价
  - 商品 X：积分价 100，库存 ≥ 2
  - 商品 Y：库存 = 0
  - 商品 Z：库存 = 1（用于验证兑换后库存减至 0）
- 依赖：DMP 同步链路（PRD 未明确，列入待澄清）

## 1. 兑换主流程

- TC-01-01 正常兑换商品，扣减积分并扣减库存 [P0]
  - 前置条件: 账号 A 余额 ≥ 商品 X 积分价；当日兑换次数 < 3；商品 X 库存 ≥ 1
  - 操作步骤: 1. 登录账号 A，打开积分商城兑换页 2. 选择商品 X 3. 点击「兑换」
  - 预期结果:
    - 兑换成功，页面提示兑换成功
    - 账号 A 积分余额扣减商品 X 对应积分（100）
    - 商品 X 库存减 1
    - 生成兑换记录（含商品、积分、时间）

- TC-01-02 积分不足时兑换，被拦截 [P0]
  - 前置条件: 账号 B 余额 < 商品 X 积分价；商品 X 库存 ≥ 1
  - 操作步骤: 1. 登录账号 B，打开兑换页 2. 选择商品 X 3. 点击「兑换」
  - 预期结果:
    - 提示"积分不足"，兑换不成功
    - 积分余额不变
    - 商品库存不变
    - 不生成兑换记录

- TC-01-03 库存为 0 时兑换，拦截 [P0]
  - 前置条件: 商品 Y 库存 = 0
  - 操作步骤: 1. 登录账号 A，打开兑换页 2. 选择商品 Y 3. 点击「兑换」
  - 预期结果:
    - 提示"库存不足"或不可兑换（按钮置灰/禁用）
    - 积分余额不变
    - 不生成兑换记录

## 2. 库存与积分状态校验

- TC-01-04 验证兑换成功后库存正确减 1 [P0]
  - 前置条件: 商品 Z 库存 = 1
  - 操作步骤: 1. 登录账号 A，兑换商品 Z 2. 返回兑换页查看商品 Z 库存 3. 再次尝试兑换商品 Z
  - 预期结果:
    - 兑换前商品 Z 库存 = 1
    - 兑换后商品 Z 库存 = 0
    - 再次兑换被"库存不足"拦截

- TC-01-05 验证积分扣减准确性 [P0]
  - 前置条件: 账号 A 余额 = 1000；商品 X 积分价 = 100
  - 操作步骤: 1. 兑换商品 X 2. 查看账号 A 积分余额与积分明细
  - 预期结果:
    - 兑换后余额 = 900
    - 积分明细新增一条扣减记录，金额 = 100

## 3. 幂等性

- TC-01-06 前端防连点：连续多次点击兑换，仅扣减一次 [P0]
  - 前置条件: 账号 A 余额 ≥ 商品 X 积分价 × 2；商品 X 库存 ≥ 2
  - 操作步骤: 1. 打开商品 X 兑换页 2. 快速连续点击「兑换」按钮 ≥ 5 次
  - 预期结果:
    - 仅生成 1 条兑换记录
    - 积分仅扣减一次（100）
    - 库存仅减 1
    - 后续点击提示防重复或无响应

- TC-01-07 服务端幂等键：重复提交同一幂等请求不重复扣分 [P0]
  - 前置条件: 账号 A 余额 ≥ 商品 X 积分价；商品 X 库存 ≥ 1
  - 操作步骤: 1. 抓取兑换请求，记录请求体与幂等键 2. 在短时间内使用同一幂等键重复提交 ≥ 2 次
  - 预期结果:
    - 服务端仅处理一次
    - 积分扣减一次、库存减 1、生成 1 条记录
    - 重复请求返回幂等结果（同首次响应或明确幂等提示）

## 4. 限频与积分有效期

- TC-01-08 每人每日第 3 次兑换成功 [P0]
  - 前置条件: 账号 A 当日已成功兑换 2 次，余额充足、库存充足
  - 操作步骤: 1. 再次发起兑换
  - 预期结果:
    - 第 3 次兑换成功
    - 积分、库存、兑换记录按规则正确更新

- TC-01-09 每人每日限兑 3 次（自然日）- 第 4 次拦截 [P0]
  - 前置条件: 账号 A 当日已成功兑换 3 次
  - 操作步骤: 1. 再次发起兑换
  - 预期结果:
    - 提示当日兑换次数已达上限
    - 积分不扣减、库存不减、不生成记录

- TC-01-10 自然日切换后兑换次数重置 [P1]
  - 前置条件: 账号 A 昨日已兑换 3 次
  - 操作步骤: 1. 当日（自然日切换后）再次发起兑换
  - 预期结果:
    - 兑换成功，当日次数计数从 0 开始

- TC-01-11 积分次年 3 月 31 日统一清零 [P1]
  - 前置条件: 测试账号余额 > 0
  - 操作步骤: 1. 通过修改系统时间/触发定时任务模拟至次年 3 月 31 日清零时点 2. 查看积分余额
  - 预期结果:
    - 余额清零为 0
    - 清零后兑换因积分不足被拦截

## 5. 兑换记录展示

- TC-01-12 兑换记录可在「我的-兑换记录」查看，字段完整 [P1]
  - 前置条件: 账号 A 至少 1 条成功兑换记录
  - 操作步骤: 1. 进入「我的-兑换记录」
  - 预期结果:
    - 展示兑换记录列表
    - 每条记录含商品、扣减积分、兑换时间
    - 信息与实际兑换一致（与 TC-01-01 结果一致）

## 6. 异步链路（待澄清）

- TC-01-13 兑换成功后 DMP 同步延迟不影响主流程 [P2]
  - 前置条件: DMP 同步链路正常
  - 操作步骤: 1. 兑换商品 X 2. 观察主流程返回与 DMP 同步状态
  - 预期结果:
    - 兑换主流程结果不受 DMP 同步延迟影响
    - DMP 同步异步进行（待 PRD 确认是否在范围内）
