## 导读区

### 功能简介 + 角色表

| 角色 | 用它做什么 |
|------|-----------|
| 运营人员 | 通过后台注销违规用户账号 |
| 普通用户（会员） | 修改自己的昵称、开通/查看 VIP 状态 |
| 系统（定时任务） | 每日凌晨 3 点清理已注销用户的搜索索引 |

### 术语表

| 术语 | 中文名 | 一句话解释 |
|------|--------|-----------|
| users | 用户表 | 存储用户账号、昵称、VIP 到期时间等核心字段 |
| user_profiles | 用户公开资料表 | 存储用户头像和简介，随账号创建 |
| orders | 订单表 | 存储用户历史订单，通过用户 ID 关联 |
| nickname | 昵称字段 | 用户表中的昵称列，需求要求 1–20 个字符 |
| vip_expire_at | VIP 到期时间字段 | 用户表中记录 VIP 到期时刻的列 |
| deleted | 软删除标记字段 | 用户表中的历史遗留字段，当前注销代码路径不写入此字段 |
| 每日清理任务 | 定时清理任务 | 每日凌晨 3 点执行，将已注销用户从搜索索引移除 |
| 搜索索引 | search index | 存储用户公开资料的搜索索引，供搜索功能使用 |
| 硬删除 | 物理删除 | 直接从数据库 DELETE 记录，不留软删除标记 |

### 图例

| 标记 | 含义 |
|------|------|
| [P0] | 冒烟测试用例，主流程核心路径，失败则功能不可用 |

| [需专业环境] | 需搜索索引等非标准测试环境 |
