## 1. 需求目标

| 编号 | 目标 | 来源 |
|------|------|------|
| G1 | 提升用户活跃度 | PRD-目标 |
| G2 | 提升用户复购率 | PRD-目标 |

## 2. 功能范围

### 2.1 功能范围（In Scope）

| 编号 | 功能模块 | 说明 |
|------|----------|------|
| F1 | 会员等级管理 | 普通、银卡、金卡（铂金待澄清）三级/四级体系，不同等级对应不同积分获取系数 |
| F2 | 积分获取 | 消费积分、签到积分、评价积分 |
| F3 | 积分消耗 | 积分商城兑换、积分抵现 |
| F4 | 积分有效期管理 | 永久有效 / 年度清零（两者矛盾，待澄清） |
| F5 | 积分状态管理 | 正常、冻结、已消耗、已过期及状态流转 |
| F6 | 退款积分扣回 | 订单退款时扣回对应积分 |

### 2.2 非目标（Out of Scope）

| 编号 | 非功能项 | 说明 |
|------|----------|------|
| N1 | 会员等级升降级规则 | PRD 仅定义等级与系数，未定义升级/降级条件与流程 |
| N2 | 积分转赠 | PRD 未提及 |
| N3 | 积分商城商品管理 | PRD 仅提及"按商品标定积分价兑换"，商品上下架、库存等未纳入 |
| N4 | 风控扣分规则配置 | PRD 仅列为依赖，具体规则未纳入本需求范围 |
| N5 | 积分活动运营（如双倍积分活动等） | PRD 未提及 |

## 3. 角色

| 角色 | 说明 | 来源 |
|------|------|------|
| 普通会员 | 基础等级用户，积分获取系数待澄清（默认 1 倍） | PRD-会员等级 |
| 银卡会员 | 积分获取系数 1.2 倍 | PRD-积分获取 |
| 金卡会员 | 积分获取系数 2 倍 | PRD-会员等级/积分获取 |
| 铂金会员 | 积分获取系数 3 倍（等级定义未列入三级体系，待澄清） | PRD-会员等级 |
| 财务 | 要求年度积分清零以控制负债 | PRD-积分有效期附注 |
| 风控系统 | 异常行为扣分（系统角色） | PRD-依赖 |

## 4. 输入/输出

### 4.1 输入

| 编号 | 输入项 | 来源 | 说明 |
|------|--------|------|------|
| IN1 | 消费订单完成事件 | 订单系统 | 触发消费积分发放，含订单金额、用户等级 |
| IN2 | 订单退款事件 | 订单系统 | 触发积分扣回，含退款金额/比例 |
| IN3 | 签到请求 | 用户端 | 每日签到 |
| IN4 | 订单评价提交 | 用户端 | 评价后发放积分 |
| IN5 | 积分商城兑换请求 | 用户端 | 含目标商品及数量 |
| IN6 | 积分抵现请求 | 用户端/订单系统 | 下单时选择积分抵现 |
| IN7 | 风控异常行为事件 | 风控系统 | 异常行为扣分 |

### 4.2 输出

| 编号 | 输出项 | 接收方 | 说明 |
|------|--------|--------|------|
| OUT1 | 积分账户余额与状态 | 用户端 | 正常/冻结/已消耗/已过期 |
| OUT2 | 积分流水记录 | 用户端/财务 | 获取/消耗/扣回/过期明细 |
| OUT3 | 兑换结果（成功/失败） | 用户端 | 积分商城兑换结果 |
| OUT4 | 抵现结果（抵扣金额） | 订单系统 | 返回可抵扣金额 |
| OUT5 | 退款扣回结果 | 订单系统 | 扣回积分数（或扣至 0） |

## 5. 状态与流转

### 5.1 积分状态定义

| 状态 | 说明 | 来源 |
|------|------|------|
| 正常 | 可用积分，用户可消费 | PRD-积分状态 |
| 冻结 | 已发起兑换但未最终确认，不可用 | PRD-积分状态 |
| 已消耗 | 兑换成功，积分已使用 | PRD-积分状态 |
| 已过期 | 年度清零导致过期（与"永久有效"矛盾，待澄清） | PRD-积分状态/积分有效期附注 |

### 5.2 状态流转图（文本描述）

```
                 ┌──────────────────────────────────┐
                 │                                  │
                 ▼                                  │
[初始] ──获取──> 正常 ──发起兑换──> 冻结             │
                 │                   │             │
                 │                   ├──成功──> 已消耗
                 │                   │             │
                 │                   └──失败──> 正常（解冻回退）
                 │                                  │
                 └──年度清零──> 已过期               │
                                   │               │
                                   └──(终态)       │
                                   │               │
                 ┌─────────────────┘               │
                 │ 退款扣回：从"正常"余额中扣减      │
                 │   若不足，扣至 0 为止            │
                 └──────────────────────────────────┘
```

### 5.3 状态流转规则

| 编号 | 流转规则 | 来源 |
|------|----------|------|
| ST1 | 积分获取后进入"正常"状态 | PRD-积分状态（推导） |
| ST2 | 用户发起积分商城兑换后，对应积分由"正常"→"冻结" | PRD-积分状态 |
| ST3 | 兑换成功，冻结积分由"冻结"→"已消耗" | PRD-积分状态 |
| ST4 | 兑换失败，冻结积分由"冻结"→"正常"（解冻） | PRD-积分状态 |
| ST5 | 年度清零时，上年度获取的"正常"积分→"已过期" | PRD-积分有效期附注 |
| ST6 | 积分抵现是否走冻结流程——待澄清 | — |

## 6. 业务规则

### 6.1 会员等级与积分获取系数

| 规则编号 | 规则内容 | 来源 |
|----------|----------|------|
| BR1 | 会员等级分为普通、银卡、金卡三级 | PRD-会员等级 |
| BR2 | 金卡会员积分获取系数为 2 倍 | PRD-会员等级 |
| BR3 | 铂金会员积分获取系数为 3 倍（铂金等级未列入 BR1 的三级定义，存在矛盾） | PRD-会员等级 |
| BR4 | 银卡会员积分获取系数为 1.2 倍 | PRD-积分获取 |
| BR5 | 普通会员积分获取系数未明确（默认假设为 1 倍） | PRD-积分获取（推导） |

### 6.2 积分获取规则

| 规则编号 | 规则内容 | 来源 |
|----------|----------|------|
| BR6 | 消费 1 元 = 1 积分（基础系数），按会员等级系数放大 | PRD-积分获取 |
| BR7 | 消费积分 = 消费金额 × 等级系数 | PRD-积分获取（推导） |
| BR8 | 签到每日 +5 积分 | PRD-积分获取 |
| BR9 | 连续签到 7 天额外 +50 积分 | PRD-积分获取 |
| BR10 | 评价订单 +10 积分/单 | PRD-积分获取 |
| BR11 | 评价订单积分每日上限 3 单（即每日最多 30 积分） | PRD-积分获取 |

### 6.3 积分消耗规则

| 规则编号 | 规则内容 | 来源 |
|----------|----------|------|
| BR12 | 积分商城兑换按商品标定积分价兑换 | PRD-积分消耗 |
| BR13 | 积分抵现比率：100 积分 = 1 元 | PRD-积分消耗 |
| BR14 | 积分抵现上限：单笔订单最高抵订单金额的 50% | PRD-积分消耗 |

### 6.4 积分有效期规则

| 规则编号 | 规则内容 | 来源 |
|----------|----------|------|
| BR15 | 积分永久有效 | PRD-积分有效期 |
| BR16 | 每年 12 月 31 日对上年度获取的积分清零（与 BR15 矛盾） | PRD-积分有效期附注 |

### 6.5 退款规则

| 规则编号 | 规则内容 | 来源 |
|----------|----------|------|
| BR17 | 订单退款时，该订单获取的积分相应扣回 | PRD-退款规则 |
| BR18 | 已消耗的积分不足扣回时，扣至 0 为止 | PRD-退款规则 |

### 6.6 风控规则

| 规则编号 | 规则内容 | 来源 |
|----------|----------|------|
| BR19 | 风控系统可对异常行为进行扣分 | PRD-依赖 |

## 7. 异常

| 编号 | 异常场景 | 触发条件 | 处理方式 | 来源 |
|------|----------|----------|----------|------|
| E1 | 兑换失败 | 发起积分商城兑换后失败 | 冻结积分解冻回正常状态 | PRD-积分状态 |
| E2 | 退款时积分不足扣回 | 订单退款时该订单获取的积分已被消耗，剩余正常积分不足 | 扣至 0 为止 | PRD-退款规则 |
| E3 | 抵现积分超出上限 | 用户选择抵现的积分对应的金额超过订单金额 50% | 限制为订单金额 50% 对应的积分 | PRD-积分消耗（推导） |
| E4 | 签到中断后连续天数处理 | 连续签到中断 | 待澄清——重置连续天数？补签规则？ | PRD-积分获取 |
| E5 | 评价超过每日上限 | 当日已评价 3 单后继续评价 | 不再发放积分 | PRD-积分获取 |
| E6 | 风控异常行为扣分 | 风控系统判定异常 | 扣分，具体规则待澄清 | PRD-依赖 |
| E7 | 积分余额不足兑换 | 用户积分余额 < 商品积分价 | 兑换请求拒绝 | PRD-积分消耗（推导） |
