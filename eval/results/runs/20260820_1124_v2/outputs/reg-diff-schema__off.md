## 待澄清

1. **calc_fee >500 档位是否为死代码**：`validate_coupon`（含 `validate_amount`）在 `calc_fee` 之前执行，amount>500 会被拦截，5 元档位不可达。需确认是否存在绕过 `validate_amount` 的创建路径，或 `calc_fee` 是否有其他调用方。
2. **TC-03-01 标准测试数据面额范围**：批量导入标准文件是否含 501–1000 面额数据；若含，测试数据须更新至新上限 500 以内，否则用例将因校验收紧而失败。
3. **Coupon 模型 fee 字段定义**：diff 中 `Coupon.create(fee=fee, **data)` 新增 fee 参数，但 ORM 模型/数据库 migration 未在 diff 中体现，需确认字段已存在，否则创建报错。
4. **calc_fee 单测覆盖**：该函数为新增逻辑，建议补充档位边界用例（amount = 1, 100, 101, 500），当前 Schema 中无对应用例。
