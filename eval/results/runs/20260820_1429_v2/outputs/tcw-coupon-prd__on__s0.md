# 图券商城管理后台 - 优惠券创建功能 测试用例

## 导读

### 功能简介与角色表

本功能允许运营人员在管理后台创建优惠券模板，供 C 端用户领取使用。券创建后处于"待发布"状态，运营可发布后进入"已发布"状态，到达结束时间后自动变为"已结束"。

| 角色 | 可执行操作 |
|------|-----------|
| 运营 | 创建优惠券、编辑优惠券（待发布状态全字段编辑，已发布状态仅发放总量可调大）、发布优惠券 |
| 管理员 | 运营全部操作 + 对已发布的券手动提前结束 |

### 术语表

| 术语 | 中文名 | 说明 |
|------|--------|------|
| 无门槛券 | 使用门槛为 0 的优惠券 | 用户领取后无最低消费限制即可使用 |
| 有门槛券 | 使用门槛大于 0 的优惠券 | 用户需满足最低消费金额才能使用 |
| 固定时间段有效期 | 开始时间至结束时间有效 | 优惠券在此时间段内有效 |
| 领取后 N 天有效 | 领取后 N 个自然日有效 | 用户领取后 N 天内可使用 |
| 待发布 | 优惠券初始状态 | 刚创建未发布，可编辑全部字段 |
| 已发布 | 优惠券已上线 | C 端用户可领取使用，仅可编辑发放总量（只能调大） |
| 已结束 | 优惠券已失效 | 不可编辑，用户不可领取 |

## 1. 优惠券创建

> 前置：运营已登录管理后台，已到达优惠券创建页面（入口路径待确认，见导读区 TODO）

### 1.1 创建-正向流程

- **TC-01-01 创建固定时间段优惠券并提交成功** [P0]（SMOKE-1）
  - 操作步骤: 1. 在优惠券创建页面填写券名称"满100减20券" 2. 填写面额"20" 3. 填写使用门槛"100" 4. 选择有效期类型"固定时间段"，设置开始时间为今天、结束时间为30天后 5. 填写发放总量"5000" 6. 填写每人限领"3" 7. 点击"提交"按钮
  - 预期结果: 提交成功，页面跳转至优惠券列表，列表中新增一张名称为"满100减20券"的优惠券，状态显示"待发布"，面额20元、使用门槛100元、发放总量5000张、每人限领3张均与填写一致

- **TC-01-02 创建领取后N天有效优惠券并提交成功** [P0]（SMOKE-2）
  - 操作步骤: 1. 在优惠券创建页面填写券名称"新人立减5元券" 2. 填写面额"5" 3. 填写使用门槛"0" 4. 选择有效期类型"领取后N天有效"，填写N为"7" 5. 填写发放总量"10000" 6. 填写每人限领"1" 7. 点击"提交"按钮
  - 预期结果: 提交成功，页面跳转至优惠券列表，列表中新增一张名称为"新人立减5元券"的优惠券，状态显示"待发布"，有效期类型显示"领取后7天有效"

- **TC-01-03 有效期类型切换时表单字段联动显示** [P1]
  - 操作步骤: 1. 在优惠券创建页面选择有效期类型"固定时间段"，观察表单显示 2. 切换选择有效期类型"领取后N天有效"，观察表单显示 3. 再切换回"固定时间段"，观察表单显示
  - 预期结果: 选择"固定时间段"时显示开始时间、结束时间两个字段；切换到"领取后N天有效"时隐藏开始/结束时间字段，显示N天输入框；切换回"固定时间段"时恢复显示开始/结束时间字段

  - 预期结果: 提交按钮置灰不可点击

- **TC-01-05 券名称输入恰好20个字符提交成功** [P2]

  - 预期结果: 提交成功，优惠券列表新增该券，名称完整显示为20个字符

- **TC-01-06 券名称输入21个字符时字段下方红字提示** [P2]

  - 预期结果: 券名称字段下方出现红字错误提示，无法提交（提交按钮置灰或提交后拦截）

- **TC-01-07 同商户下输入已存在的券名称时提示"名称已存在"** [P1]

  - 预期结果: 提交成功，商户B下新增该券，无"名称已存在"提示
