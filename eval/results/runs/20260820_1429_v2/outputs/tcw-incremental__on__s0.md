# 优惠券创建 测试用例

> **功能简介**：运营在管理后台创建优惠券模板，供 C 端用户领取。
>
> **角色**：运营 -> 创建/编辑/发布优惠券；运营组长 -> 创建/编辑/发布优惠券 + 手动提前结束；管理员 -> 手动提前结束。

**术语表**：券模板=优惠券的定义记录；门槛=订单需达到的金额；每人限领=每个用户最多可领取的券数量。

**图例**：P0=冒烟 / P1=常规（默认）/ P2=边界低频。

## 1. 创建优惠券

> 前置：运营账号已登录管理后台，进入「营销中台 -> 券工场 -> 新建券」

- **TC-01-01 正常创建满减券** [P0]（SMOKE-1）[已变更]
  - 操作步骤: 1. 填写券名称"周年庆满100减20" 2. 面额填 20 3. 门槛填 100 4. 有效期选固定时间段（明天至后30天）5. 发放总量 1000 6. 每人限领填 1 7. 点击提交
  - 预期结果: 创建成功，列表出现该券，状态为待发布

- **TC-01-02 面额边界值校验** [P2] [已变更]
  - 操作步骤: 1. 面额分别填写 0、1、500、501 提交（其余字段均合法）
  - 预期结果: 0 与 501 提示"面额需为 1-500 的整数"被拦截；1 与 500 创建成功

- **TC-01-03 门槛小于面额拦截** [P1]
  - 操作步骤: 1. 面额填 20，门槛填 10，其余合法，提交
  - 预期结果: 提示"使用门槛不能低于面额"，提交被拦截

- **TC-01-04 券名称重复拦截** [P1]
  - 前置条件: 已存在券"周年庆满100减20"
  - 操作步骤: 1. 新建券，名称填"周年庆满100减20"，其余合法，提交
  - 预期结果: 提示"名称已存在"，创建被拦截

- **TC-01-05 每人限领字段校验** [P2] [新增]
  - 操作步骤: 1. 新建券页面，不填写每人限领，观察字段默认值 2. 清空每人限领字段，其余合法，提交 3. 每人限领分别填写 0、1、10、11 提交（其余字段均合法）
  - 预期结果: 步骤 1 默认显示 1；步骤 2 提示"每人限领为必填项"被拦截；步骤 3 中 0 与 11 提示"每人限领需为 1-10 的整数"被拦截，1 与 10 创建成功

- **TC-01-06 发放总量上限校验** [P2] [新增]
  - 操作步骤: 1. 发放总量分别填写 50000、50001，其余合法，提交
  - 预期结果: 50001 提示"发放总量不能超过 50000"被拦截；50000 创建成功

## 2. 发布与状态

> 前置：已存在一张待发布状态的券

- **TC-02-01 发布优惠券** [P0]（SMOKE-2）
  - 操作步骤: 1. 在券列表对待发布券点击「发布」
  - 预期结果: 券状态变为已发布，C 端可见可领

- **TC-02-02 到期自动结束** [P1]
  - 操作步骤: 1. 将一张已发布券的结束时间改为 2 分钟后（用编辑发放总量外的字段需待发布态，故创建时设短有效期）2. 等待到期
  - 预期结果: 到期后 1 小时内状态自动变为已结束，超过 1 小时未变判失败

- **TC-02-03 管理员手动提前结束** [P1] [已变更]
  - 前置条件: 已存在一张已发布状态的券
  - 操作步骤: 1. 管理员账号登录管理后台 2. 在券列表对已发布券点击「提前结束」
  - 预期结果: 券状态变为已结束，C 端不可再领取

- **TC-02-04 运营组长手动提前结束** [P1] [新增]
  - 前置条件: 已存在一张已发布状态的券，运营组长账号已就绪
  - 操作步骤: 1. 运营组长账号登录管理后台 2. 进入「营销中台 -> 券工场 -> 活动列表」3. 对已发布券点击「提前结束」
  - 预期结果: 券状态变为已结束，C 端不可再领取

- **TC-02-05 普通运营无提前结束权限** [P2] [新增]
  - 前置条件: 已存在一张已发布状态的券
  - 操作步骤: 1. 运营账号登录管理后台 2. 进入「营销中台 -> 券工场 -> 活动列表」3. 查看已发布券的操作选项
  - 预期结果: 券列表中不展示「提前结束」按钮（或按钮置灰不可点击），运营无法手动结束券
