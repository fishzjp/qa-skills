## 导读

### 功能简介与角色

本模块覆盖用户资料管理核心功能：用户注销、昵称修改、VIP 开通与到期判断、已注销用户搜索索引清理。

| 角色 | 使用功能 |
|------|---------|
| 运营人员 | 通过运营后台注销违规用户 |
| 普通用户（会员） | 修改自己的昵称、开通 VIP 会员 |
| 系统（定时任务） | 每日凌晨 3 点执行搜索索引清理 |

> **执行模型说明**：本模块被测代码为后端服务（无 UI 层代码），测试用例采用「测试-开发协作清单」格式。操作步骤标注「请开发执行」，预期结果标注「请开发反馈」。如存在运营后台 UI 或用户端 UI，部分用例可转为测试独立执行（见待澄清 Q8）。
