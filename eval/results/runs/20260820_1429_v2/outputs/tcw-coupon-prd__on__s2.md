# 优惠券创建功能 测试用例

## 导读

### 功能简介

运营人员在图券商城管理后台创建优惠券模板，供 C 端用户领取使用。支持创建、编辑、发布、手动提前结束等操作。券有三种状态：待发布 → 已发布 → 已结束。

### 角色表

| 角色 | 可执行操作 |
|------|-----------|
| 运营 | 创建优惠券、编辑优惠券、发布优惠券 |
| 管理员 | 运营的全部操作 + 手动提前结束进行中的优惠券活动 |

| 项目 | 内容 |
|------|------|
| 管理后台入口 | TODO：向项目负责人索取管理后台 URL |
| 运营测试账号 | TODO：向项目负责人索取运营角色测试账号（含所属商户信息） |
| 管理员测试账号 | TODO：向项目负责人索取管理员角色测试账号（含所属商户信息） |
| 优惠券创建页面入口 | TODO：入口路径待确认。推测为「管理后台 → 营销中心 → 优惠券管理 → 新建优惠券」，需向产品确认 |
| 优惠券列表页面入口 | TODO：入口路径待确认。推测为「管理后台 → 营销中心 → 优惠券管理 → 活动列表」，需向产品确认 |

### 术语表

| 术语 | 说明 |
|------|------|
| 优惠券模板 | 运营创建的优惠券配置，包含面额、门槛、有效期等信息 |
| 发放总量 | 优惠券可发放的总张数 |
| 每人限领 | 单个 C 端用户最多可领取的张数 |
| 无门槛券 | 使用门槛为 0 的优惠券，下单可直接抵扣 |
| 有门槛券 | 使用门槛非 0 的优惠券，需订单金额达到门槛方可使用 |
| 商户 | 图券商城中的租户/商户单位，券名称唯一性在同商户内校验 |
| 固定时间段 | 有效期类型之一，指定开始时间和结束时间 |
| 领取后 N 天有效 | 有效期类型之一，用户领取后 N 天内有效，N 取值 1–30 |
| 提前结束 | 管理员对已发布的券手动终止活动，券状态变为已结束 |

### 图例

- **[P0]**：冒烟测试用例，主流程核心路径，失败则整个功能不可用
- **[P1]**：常规功能验证 + 常见异常处理
- **[P2]**：边界值、极端场景、低频场景
- 未标注优先级时默认 P1

## 2. 状态流转

> 状态机：
> - 待发布 --发布--> 已发布
> - 已发布 --到达结束时间（定时任务1小时内）--> 已结束
> - 已发布 --管理员手动提前结束--> 已结束
> - 已结束 --（无后续转换）-->
>
> 前置：已登录运营或管理员账号，进入优惠券列表页面（入口待确认，推测路径：管理后台 → 营销中心 → 优惠券管理 → 活动列表）
