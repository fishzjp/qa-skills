# 客服工单系统状态流转测试用例

## 1. 工单创建与初始状态
### 1.1 用户创建工单
- **前置条件**：用户已登录客服工单系统
- **操作步骤**：用户填写工单信息并提交创建
- **预期结果**：工单创建成功，状态显示为「待分配」，工单进入待分配池

## 2. 待分配状态流转
### 2.1 客服接单（待分配 -> 处理中）
- **前置条件**：工单状态为「待分配」，客服已登录工作台
- **操作步骤**：客服在工单池点击「接单」
- **预期结果**：工单状态变更为「处理中」，工单与该客服建立持有关系，工单从待分配池移除
### 2.2 用户撤单（待分配 -> 已取消）
- **前置条件**：工单状态为「待分配」，用户已登录
- **操作步骤**：用户在工单详情点击「撤单」并确认
- **预期结果**：工单状态变更为「已取消」，工单从待分配池移除
### 2.3 已取消终态校验
- **前置条件**：工单状态为「已取消」
- **操作步骤**：尝试对工单进行接单、撤单等状态变更操作
- **预期结果**：所有状态变更按钮不可见或置灰，无法进行操作

## 3. 处理中状态流转
### 3.1 客服提交解决方案（处理中 -> 待用户确认）
- **前置条件**：工单状态为「处理中」，由该客服持有
- **操作步骤**：客服填写解决方案并点击「提交方案」
- **预期结果**：工单状态变更为「待用户确认」，用户侧可查看方案
### 3.2 客服转派（处理中 -> 待分配）
- **前置条件**：工单状态为「处理中」，由该客服持有
- **操作步骤**：客服点击「转派」，填写转派原因，确认转派
- **预期结果**：工单状态变更为「待分配」，工单回到待分配池，系统记录转派原因及操作日志
### 3.3 转派原因必填校验
- **前置条件**：工单状态为「处理中」，由该客服持有
- **操作步骤**：客服点击「转派」，不填写转派原因，尝试确认
- **预期结果**：操作被拦截，提示转派原因为必填项

## 4. 待用户确认状态流转
### 4.1 用户确认解决（待用户确认 -> 已完成）
- **前置条件**：工单状态为「待用户确认」
- **操作步骤**：用户在工单详情点击「确认解决」
- **预期结果**：工单状态变更为「已完成」
### 4.2 用户拒绝方案（待用户确认 -> 处理中）
- **前置条件**：工单状态为「待用户确认」
- **操作步骤**：用户点击「拒绝」，填写拒绝理由，确认提交
- **预期结果**：工单状态变更为「处理中」，原客服重新持有，系统记录拒绝理由
### 4.3 拒绝理由必填校验
- **前置条件**：工单状态为「待用户确认」
- **操作步骤**：用户点击「拒绝」，不填写拒绝理由，尝试确认
- **预期结果**：操作被拦截，提示拒绝理由为必填项
### 4.4 系统自动确认（待用户确认 -> 已完成）
- **前置条件**：工单状态为「待用户确认」
- **操作步骤**：工单进入该状态后，用户 72 小时内无任何操作
- **预期结果**：72 小时后系统自动将状态变更为「已完成」，标记为系统自动确认

## 5. 已完成状态流转
### 5.1 用户申诉通过（已完成 -> 处理中）
- **前置条件**：工单状态为「已完成」，且完成时间在 7 天内
- **操作步骤**：用户点击「申诉」提交申请 -> 管理员在后台审批通过
- **预期结果**：申诉通过后工单状态变更为「处理中」，标记为重新打开
### 5.2 用户申诉拒绝
- **前置条件**：工单状态为「已完成」，且完成时间在 7 天内
- **操作步骤**：用户点击「申诉」提交申请 -> 管理员在后台审批拒绝
- **预期结果**：工单状态保持「已完成」不变
### 5.3 已完成超期终态校验
- **前置条件**：工单状态为「已完成」，且完成时间超过 7 天
- **操作步骤**：查看工单详情，尝试发起申诉
- **预期结果**：「申诉」按钮不可见或置灰，工单为终态不可变更

## 6. 并发与异常约束测试
### 6.1 多客服并发接单
- **前置条件**：工单状态为「待分配」
- **操作步骤**：客服 A 与客服 B 同时对同一工单点击「接单」
- **预期结果**：仅一名客服接单成功，状态变为「处理中」并建立持有关系；另一名客服接单失败并提示工单已被接单
### 6.2 用户撤单与客服接单并发
- **前置条件**：工单状态为「待分配」
- **操作步骤**：用户撤单与客服接单操作同时发起
- **预期结果**：以先到达系统的操作为准；后到操作失败并给予明确提示（如“工单已撤单”或“工单已被接单”）
### 6.3 同一工单客服持有唯一性
- **前置条件**：工单状态为「处理中」，由客服 A 持有
- **操作步骤**：客服 B 尝试对该工单进行操作（如提交方案、转派）
- **预期结果**：客服 B 无法操作，提示工单正由其他客服处理中

## 7. 角色权限边界测试
### 7.1 用户角色权限
- **预期结果**：仅能执行创建、撤单、确认解决、拒绝、申诉操作；无接单、提交方案、转派、审批权限
### 7.2 客服角色权限
- **预期结果**：仅能执行接单、提交方案、转派操作；无撤单、确认解决、拒绝、申诉、审批权限
### 7.3 管理员角色权限
- **预期结果**：仅能执行申诉审批操作；无工单流转常规操作权限

## 8. 待澄清清单
- 「待用户确认」72 小时自动确认的计时起点是进入该状态的确切时刻，还是按自然日计算？
- 用户申诉审批是否有处理时限？审批期间工单在前台显示为何种状态？
- 重新打开（已完成 -> 处理中）的工单是否默认分配给原处理客服，还是重新进入待分配池？
- 转派原因和拒绝理由是否有字数上限或格式要求？
- 客服转派工单后，是否限制该客服再次接手同一工单？
- 用户在「处理中」或「待用户确认」阶段是否允许撤单？PRD 仅说明「待分配」可撤单。
