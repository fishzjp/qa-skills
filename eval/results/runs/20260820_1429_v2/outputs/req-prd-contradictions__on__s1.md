# 需求模型：会员积分体系

> 源文档：PRD《会员积分体系》v0.9（草稿）  
> 证据体系：E1（文档证据）为主；推断项标注 Inference 并降级处理  
> 待澄清事项：20 项（均未裁决）

---

## 1. 需求目标

| 字段 | 内容 |
|------|------|
| goal | 提升用户活跃与复购，建立积分获取与消耗闭环 |
| 成功标准 | PRD 未给出可量化指标（待澄清，见 Q17） |
| evidence | E1 / PRD v0.9「目标」段 |
| status | Fact（目标陈述）/ Inference（成功标准缺失） |

---

## 2. 功能范围（含非目标）

### 2.1 功能范围

- 会员等级体系（普通 / 银卡 / 金卡，是否含铂金待澄清）
- 积分获取：消费返积分、签到、评价订单
- 积分消耗：积分商城兑换、下单积分抵现
- 积分生命周期：状态流转、有效期管理、退款扣回
- 风控联动：异常行为扣分

### 2.2 非目标

| 非目标 | 说明 | evidence |
|--------|------|----------|
| 会员等级升降级规则 | PRD 全文未涉及升级/降级条件，推断为独立模块管理 | Inference / E1（全文缺失） |
| 积分运营后台 | PRD 未提及后台管理功能 | Inference / E1（全文缺失） |
| 积分转赠 | PRD 未提及用户间积分转移 | Inference / E1（全文缺失） |

> ⚠ 非目标为推断，需产品确认（见 Q16）。
