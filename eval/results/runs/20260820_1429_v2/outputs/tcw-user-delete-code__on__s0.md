## 导读

### 功能简介与角色表

本模块覆盖用户资料管理的四项功能：用户注销（运营操作）、昵称修改（用户自助）、VIP 开通与状态查询（用户自助）、已注销用户搜索索引每日清理（系统定时任务）。

| 角色 | 可执行操作 |
|------|-----------|
| 运营人员 | 通过运营后台注销违规用户 |
| 普通用户 | 修改自己的昵称、开通 VIP、查询 VIP 状态 |
| 系统（定时任务） | 每日凌晨 3 点执行搜索索引清理 |

### 术语表

| 术语 | 中文名 | 一句话解释 |
|------|--------|-----------|
| 注销 | 账号删除 | 删除用户账号，用户不可再登录，公开内容下线 |
| 硬删除 | 物理删除 | 直接从数据库删除记录，不可恢复（区别于标记删除） |
| 软删除标记 | deleted 字段 | 用户表中的历史遗留字段，当前代码路径不写入 |
