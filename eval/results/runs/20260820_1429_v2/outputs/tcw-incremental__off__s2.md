# 优惠券创建 测试用例

> **功能简介**：运营在管理后台创建优惠券模板，供 C 端用户领取。
>
> **角色**：运营 -> 创建/编辑/发布优惠券；管理员、运营组长 -> 手动提前结束。

**环境与账号**：

| 项 | 值 |
|----|----|
| 管理后台入口 | TODO：向运维索取测试环境地址 |
| 运营测试账号 | TODO：向运营组长索取 |
| 管理员测试账号 | TODO：向运营组长索取 |
| 运营组长测试账号 | TODO：向运营组长索取 |

**术语表**：券模板=优惠券的定义记录；门槛=订单需达到的金额。

**图例**：P0=冒烟 / P1=常规（默认）/ P2=边界低频。

## 1. 创建优惠券

> 前置：运营账号已登录管理后台，进入「营销中台 -> 券工场 -> 新建券」

- **TC-01-01 正常创建满减券** [P0]（SMOKE-1） [v1.3变更]
  - 操作步骤: 1. 填写券名称"周年庆满100减20" 2. 面额填 20 3. 门槛填 100 4. 有效期选固定时间段（明天至后30天）5. 发放总量 1000 6. 每人限领保持默认 7. 点击提交
  - 预期结果: 创建成功，列表出现该券，状态为待发布，每人限领默认值为1
- **TC-01-02 面额边界值校验** [P2] [v1.3变更]
  - 操作步骤: 1. 面额分别填写 0、1、500、501 提交
  - 预期结果: 0 与 501 提示"面额需为 1-500 的整数"被拦截；1 与 500 创建成功
- **TC-01-03 门槛小于面额拦截** [P1]
  - 操作步骤: 1. 面额填 20，门槛填 10，其余合法，提交
  - 预期结果: 提示"使用门槛不能低于面额"，提交被拦截
- **TC-01-04 券名称重复拦截** [P1]
  - 前置条件: 已存在券"周年庆满100减20"
  - 操作步骤: 1. 新建券，名称填"周年庆满100减20"，其余合法，提交
  - 预期结果: 提示"名称已存在"，创建被拦截
- **TC-01-05 每人限领边界值校验** [P2] [v1.3新增]
  - 操作步骤: 1. 其余字段合法，每人限领分别填写 0、1、10、11 提交
  - 预期结果: 0 与 11 提示"每人限领需为 1-10 的整数"被拦截；1 与 10 创建成功
- **TC-01-06 发放总量上限校验** [P2] [v1.3新增]
  - 操作步骤: 1. 其余字段合法，发放总量分别填写 50000、50001 提交
  - 预期结果: 50000 创建成功；50001 提示"发放总量不可超过 50000"被拦截

## 2. 发布与状态

> 前置：已存在一张待发布状态的券

- **TC-02-01 发布优惠券** [P0]（SMOKE-2）
  - 操作步骤: 1. 在券列表对待发布券点击「发布」
  - 预期结果: 券状态变为已发布，C 端可见可领
- **TC-02-02 到期自动结束** [P1]
  - 操作步骤: 1. 将一张已发布券的结束时间改为 2 分钟后（用编辑发放总量外的字段需待发布态，故创建时设短有效期）2. 等待到期
  - 预期结果: 到期后 1 小时内状态自动变为已结束，超过 1 小时未变判失败
- **TC-02-03 手动提前结束权限校验** [P1] [v1.3变更]
  - 操作步骤: 1. 管理员账号登录，对已发布券点击「提前结束」 2. 运营组长账号登录，对另一张已发布券点击「提前结束」 3. 普通运营账号登录，对已发布券尝试点击「提前结束」
  - 预期结果: 管理员与运营组长操作成功，券状态变为已结束，C 端不可再领取；普通运营无「提前结束」按钮或提示无权限被拦截
