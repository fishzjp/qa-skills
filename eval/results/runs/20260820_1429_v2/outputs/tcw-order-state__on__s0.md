# 客服工单系统 测试用例

## 导读

### 功能简介

客服工单系统用于管理用户问题工单的全生命周期。工单在 5 个状态间流转：待分配、处理中、待用户确认、已完成、已取消。用户创建工单后进入待分配池，客服接单处理并提交解决方案，用户确认后工单完成；用户也可撤单、拒绝方案、申诉重开。

### 角色表

| 角色 | 用它做什么 |
|------|-----------|
| 用户 | 创建工单、撤单、确认解决、拒绝方案、发起申诉 |
| 客服 | 接单、提交解决方案、转派工单 |
| 管理员 | 审批用户申诉 |

### 术语表

| 术语 | 中文名 | 说明 |
|------|--------|------|
| 工单池 | 待分配工单池 | 所有处于"待分配"状态的工单集合，客服可从中接单 |
| 转派 | 转派工单 | 客服将"处理中"的工单退回待分配池，由其他客服接手 |
| 申诉 | 完成工单申诉 | 用户对"已完成"工单在 7 天内发起重新处理请求 |
| 自动确认 | 超时自动确认 | 待用户确认状态满 72 小时无操作，系统自动标记为已完成 |
| 终态 | 终态状态 | 已取消和已完成（超 7 天）状态，不可再变更 |

### 状态机总览

```
[创建] --创建工单--> 待分配
待分配 --客服接单--> 处理中
待分配 --用户撤单--> 已取消（终态）
处理中 --客服提交解决方案--> 待用户确认
处理中 --客服转派--> 待分配
待用户确认 --用户确认解决--> 已完成
待用户确认 --用户拒绝--> 处理中
待用户确认 --72h超时未操作--> 已完成（系统自动确认）
已完成 --用户申诉(7天内)+管理员审批通过--> 处理中
已完成（超7天）--> 终态，不可变更
已取消 --> 终态，不可变更
```

## 1. 工单创建

### 1.1 创建工单进入待分配

> 前置：用户 test_user_01 已登录用户端

- **TC-01-01 用户创建工单，工单进入待分配** [P0]（SMOKE-1）
  - 操作步骤: 1. 在用户端进入工单创建页面 2. 填写工单标题"订单退款咨询"、问题描述"订单 TK202401150001 需要退款，请协助处理" 3. 点击"提交"按钮
  - 预期结果: 页面提示"工单创建成功"并显示工单编号，工单状态显示为"待分配"；切换到客服 agent_01 账号登录客服工作台，在工单池中能看到该工单

- **TC-01-02 创建后工单在客服端工单池可见** [P1]
  - 前置条件: 已通过 TC-01-01 创建工单（标题"订单退款咨询"）
  - 操作步骤: 1. 客服 agent_01 登录客服工作台 2. 进入工单池页面 3. 查找标题为"订单退款咨询"的工单
  - 预期结果: 工单池中显示该工单，状态为"待分配"，能看到工单标题、创建时间、创建人 test_user_01

## 2. 待分配状态

> 前置：用户 test_user_01 已创建工单（标题"订单退款咨询"，状态为待分配）；客服 agent_01 已登录客服工作台

- **TC-02-02 接单后工单池中该工单不再可见** [P1]
  - 前置条件: agent_01 已接单（TC-02-01 完成后）
  - 操作步骤: 1. 客服 agent_02 登录客服工作台 2. 进入工单池页面 3. 搜索标题"订单退款咨询"
  - 预期结果: 工单池中找不到该工单（已被 agent_01 接走）

### 2.2 用户撤单

> 前置：用户 test_user_01 已创建工单（标题"物流催单"，状态为待分配）

- **TC-02-04 撤单后客服端工单池中该工单消失** [P1]

## 待澄清清单

1. **处理中状态下用户是否可以撤单**：PRD 规则 3 仅定义"待分配 -> 用户撤单 -> 已取消"，未说明处理中状态用户能否撤单。当前用例按 PRD 定义将处理中撤单视为不可操作。若业务上应支持，需补充状态边和对应用例。

2. **72 小时超时自动确认的实现机制与时间精度**：是定时任务扫描还是请求时实时判定？若是定时任务，扫描周期是多少（影响判定时限的写法）？精确到小时还是分钟？测试环境是否有时间加速配置？

3. **7 天申诉期限的判定基准**：从工单完成时刻起算 72 小时 × 7 = 精确到秒级时间戳，还是按自然日计算（完成当天算第 0 天还是第 1 天）？

4. **申诉审批被拒绝后工单状态**：PRD 规则 9 仅定义"已完成 -> 用户申诉（7 天内）-> 处理中（需管理员审批）"，未说明审批被拒绝后的状态。当前用例假设保持"已完成"，需确认。

5. **申诉是否有中间状态**：用户提交申诉后、管理员审批前，工单状态是保持"已完成"还是有"申诉审批中"等中间状态？PRD 状态集中未定义此状态。

6. **转派后工单的可见范围**：转派后工单回到待分配池，是否对所有客服可见？原转派客服是否还能看到该工单？是否有冷却期防止原客服重新接单？

7. **并发冲突的具体提示文案**：撤单与接单并发、多客服同时接单时，后到操作失败的提示文案具体是什么？需确认以便用例精确断言。

8. **管理员审批入口路径**：PRD 提到管理员角色负责申诉审批，但未说明管理后台的具体入口路径和审批操作流程。

9. **工单创建是否有必填字段校验**：PRD 未描述工单创建时的字段校验规则（标题/描述是否必填、长度限制等），若有需补充输入校验用例。

10. **已完成超 7 天的判定方式**：是否允许在 7 天边界（第 7 天当天）申诉？还是第 7 天 23:59:59 后不可申诉？边界值需明确。
