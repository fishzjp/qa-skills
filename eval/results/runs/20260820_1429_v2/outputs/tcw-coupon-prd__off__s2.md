# 优惠券创建功能测试用例

## 1. 前置条件与环境准备
- 管理后台入口地址与测试账号（暂未提供，见待澄清清单）
- 使用运营角色账号登录管理后台
- 进入「优惠券管理」→「创建优惠券」页面
- 准备同商户下已有的优惠券名称用于唯一性校验
- 准备其他商户账号用于跨商户校验

## 2. 券名称字段测试

### 2.1 正向用例
- **TC-NAME-001 [P0]**：输入1个字符
  - 步骤：券名称输入"A"，其余字段填写有效值，提交
  - 预期：提交成功，列表中名称显示为"A"
- **TC-NAME-002 [P0]**：输入20个字符（边界值）
  - 步骤：券名称输入20个字符，提交
  - 预期：提交成功，名称保存正确
- **TC-NAME-003 [P1]**：输入中英文+数字混合名称
  - 步骤：券名称输入"新春优惠券A2024"，提交
  - 预期：提交成功，名称保存正确

### 2.2 反向用例
- **TC-NAME-004 [P0]**：券名称为空
  - 步骤：不输入券名称，填写其余必填项
  - 预期：提交按钮置灰，无法点击
- **TC-NAME-005 [P0]**：券名称超过20个字符（输入21个字符）
  - 步骤：券名称输入21个字符
  - 预期：字段下方红字提示"不超过20个字符"，不中断其他字段填写
- **TC-NAME-006 [P0]**：券名称同商户下重复
  - 步骤：输入同商户下已存在的券名称，其余字段有效，提交
  - 预期：提示"名称已存在"，提交失败
- **TC-NAME-007 [P1]**：券名称跨商户重复
  - 步骤：切换到其他商户，输入与原商户相同的券名称，提交
  - 预期：提交成功（唯一性仅同商户内校验）

## 5. 有效期类型测试

- **TC-EXP-002 [P1]**：跨度恰好等于90天（边界值）
  - 步骤：选择"固定时间段"，开始时间选择2024-01-01，结束时间选择2024-03-31（90天）

#### 反向用例
- **TC-EXP-003 [P0]**：开始时间等于结束时间

- **TC-EXP-004 [P0]**：开始时间晚于结束时间

  - 预期：红字提示"开始时间需早于结束时间"
- **TC-EXP-005 [P0]**：跨度超过90天

- **TC-EXP-006 [P1]**：未选择开始或结束时间

## 9. 状态流转测试

- **TC-STAT-001 [P0]**：待发布→已发布
