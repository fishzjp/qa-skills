- TC-NAME-007：输入中文、英文、数字混合，创建成功
- TC-NAME-008：输入特殊字符（如括号、短横线），创建成功

## 4. 业务逻辑与组合测试

## 5. 状态流转测试

### 5.1 待发布状态
- TC-STATUS-001：新建优惠券后默认状态为「待发布」
- TC-STATUS-002：待发布状态可编辑全部字段
- TC-STATUS-003：待发布状态编辑后保存，数据更新成功
- TC-STATUS-004：待发布状态可执行发布操作，状态变为「已发布」

### 5.2 已发布状态
- TC-STATUS-005：待发布券发布后状态变为「已发布」
- TC-STATUS-006：已发布状态仅发放总量字段可编辑
- TC-STATUS-007：已发布状态发放总量只能调大，调小时提示错误/禁止
- TC-STATUS-008：已发布状态编辑其他字段，不可编辑或提示不可操作
- TC-STATUS-009：已发布券到达结束时间后，1小时内自动变为「已结束」

### 5.3 已结束状态
- TC-STATUS-010：已结束状态不可编辑任何字段
- TC-STATUS-011：已结束状态不可重新发布
- TC-STATUS-012：已结束状态不可手动提前结束（已无意义）

### 5.4 手动提前结束
- TC-STATUS-013：管理员对已发布券执行手动提前结束，状态变为「已结束」
- TC-STATUS-014：运营账号无手动提前结束操作权限
- TC-STATUS-015：手动提前结束后不可恢复为「已发布」
- TC-STATUS-016：手动提前结束后券不可再被领取（C端验证）

### 5.5 自动结束定时任务
- TC-AUTO-001：券到达结束时间后，定时任务在1小时内将状态变更为「已结束」
- TC-AUTO-002：定时任务执行前券状态仍为「已发布」
- TC-AUTO-003：定时任务执行后券状态为「已结束」且不可逆
- TC-AUTO-004：多张券同时到达结束时间，定时任务批量处理无异常

## 9. 待澄清清单

- 管理后台入口地址
- 测试账号（运营角色、管理员角色）
- 券名称是否允许 emoji 和特殊字符（如 SQL 关键字）
- 面额、使用门槛等数值字段是否允许前导零（如 001）
- 发放总量与每人限领之间是否有数量关系校验（如每人限领≤发放总量）
- 固定时间段的时间精度（秒级/分钟级/小时级/日级）
- 「领取后 N 天有效」的起算时间点（领取时刻还是领取当日零点）
- 已发布券发放总量调大是否有上限限制（是否仍受 100000 上限约束）
- 手动提前结束后是否可恢复为已发布
- 系统定时任务具体执行频率（间隔多少分钟）
- 创建成功后的反馈方式（跳转列表页 / 弹窗提示 / Toast）
- 是否需要在本期覆盖 C 端领取与使用流程的联调测试
- 草稿自动保存机制是否存在
- 券名称唯一性校验是否对大小写敏感、是否去除首尾空格后比较
